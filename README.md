# SQL for Data Analysis — E-commerce

## Project Overview

This project demonstrates SQL skills for analyzing e-commerce order and customer data. It covers data retrieval, filtering, aggregation, joins, subqueries, views, and basic query optimization.

## Objectives

- Retrieve and filter structured data.
- Calculate revenue and average order value.
- Analyze customer-level sales.
- Combine related tables using SQL joins.
- Use subqueries to identify orders above average value.
- Create reusable views for sales analysis.
- Explore indexes and query execution plans.

## Tools

- MySQL
- MySQL Workbench
- SQL

## Files

- `ecommerce_analysis.sql` — SQL queries and table definitions.
- `screenshot` — Screenshot of executed queries and results.

## Key SQL Concepts

`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, aggregate functions, `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, subqueries, views, indexes, and `EXPLAIN`.

## How to Run

1. Open MySQL Workbench.
2. Connect to your local MySQL server.
3. Open `ecommerce_analysis.sql`.
4. Execute the script in order.
5. Review the output grids and execution plan.
6. Capture screenshots and save them in the `screenshots` folder.

## Learning Outcomes

This project demonstrates the use of SQL to manipulate structured data, summarize sales, analyze customers, and prepare reusable queries for business reporting.
